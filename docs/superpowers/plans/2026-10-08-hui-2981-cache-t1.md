# HUI-2981【缓存收益 T1】实施计划(C 案:本地有界 TTL 缓存)

日期:2026-10-08 · 分支:hui-2981-cache · 设计:docs/superpowers/specs/2026-10-08-hui-2981-cache-t1-design.md(阈值已冻结 §2.1)

前置事实(已完成):
- A 案索引审计:无缺失索引,B 案无可实施项(spec §3.1);
- A 案基线测量已跑:公共页 5 SQL/req P95=216ms;看板 20 SQL/req P50=274ms;
  单 SQLite 连接串行排队是主要时延来源(spec §3.2);
- 获胜方案按业主决议预置为 C(本地缓存)+ 对照验证;达标即出「不接 Redis」裁决。

## 工作项(每项一个 commit,完成即 commit+push)

### W1. readcache 包(TDD 先行)
新包 `server/internal/readcache`:
- `Cache[V]`:有界条目数(容量上限+LRU 驱逐)、TTL±抖动、epoch 校验
  (构造时注入 `Epoch func() uint64`)、singleflight(miss 并发合并,同 key
  并发只回源一次)、`Disable()`(一键禁用,单向锁存:清空+此后全部 miss)。
- 回源错误如实上抛,绝不吞成零值。
- 测试 `readcache_test.go`:命中/未命中/TTL 过期/抖动上界/epoch 失效/容量
  LRU/并发 singleflight loader 恰一次/Disable 后全 miss/错误上抛。

### W2. store 层:ResolveLink 拆纯函数 + epoch
- `store.ResolvedRows{Found,Link,Campaign,Store,HasStore,Tenant,HasTenant}` +
  纯函数 `DecideLink(rows,at) ResolvedLink`(五态+StoreUnavailable 现判窗口);
  `ResolveLink` 行为逐字节不变(flag off 路径零改动)。
- `Store.epoch atomic.Uint64` + `Epoch()`;结构性管理写同步 bump:活动
  (建/改/转态)、短码(建/停启)、门店(建/改/停启)、租户(建/改名/lifecycle)、
  lead_forms upsert、nfc_tags 变更。事实性写(public_view_stats、
  lead_submissions)不 bump——由 TTL+as_of 管陈旧。
- 测试:DecideLink 纯函数表驱动(五态×窗口边界);bump 覆盖每类结构性写。

### W3. httpapi 接线(feature flag 默认 off)
- `FEATURE_PUBLIC_CACHE` / `FEATURE_DASHBOARD_CACHE`(config,默认 off;
  off = 路径逐字节现状)。
- 公共页 GET:flag on 时走 `LoadResolvedRows`(miss 回源 4 点查)→ 缓存;
  命中 0 SQL,用缓存行 + `time.Now()` 重推导五态;brand shell 钩子保持
  现位置;负结果(NotFound)也缓存(受 epoch 管,建活动即失效)。
- 看板 GET:flag on 时按 (tenant, storeScope, window_start, window_end)
  缓存 (facts,dims,asOf);响应追加 `as_of`(仅 cache on 出现)。
- Server 构造时创建缓存(默认 TTL:公共 3s±1s、看板 10s±2s;容量:公共
  10000 条、看板 512 条),测试可替换短 TTL 实例。

### W4. E2E/不变量测试(httpapi)
`server_readcache_test.go`,全部 flag on:
1. 管理员改标题/暂停/结束/停短码/停门店/改租户名 → 消费者页下一请求立即
   新值(0 陈旧);
2. available 按当前时间现判(ends_at 改到过去 → expired);
3. 无串租户:两租户看板同窗互不可见;公共页 key=code 无跨租户面;
4. 写路径(表单 GET/留资提交/beacon)cache on 下仍直查 DB 且数据新鲜;
5. 重算一致性:已知事件集 → 缓存响应与直算响应指标逐项相等,as_of 存在;
6. Disable() 后服务正常(等效直查);并发 miss 不击穿(响应全 200、无 5xx);
7. store 层测试:ResolveLink flag-off 行为不变(既有 store_test 全过)。

### W5. C 案对照测量 + 报告
