# HUI-2390 R3 实施计划

**Goal:** 把选定的 Touch 活动交成矩阵发布草稿引用，不执行发布，也不产生顾客奖励、UGC 或线索。

**Architecture:** `server/internal/matrixhandoff` 自持草稿。Touch 活动与矩阵计划引用是不同类型。账号池和社媒秘密不进入文档。夹具客户端只返回引用或错误。

**Tech Stack:** Go `GOWORK=off`。无 HTTP，无 web。

**Spec:** `docs/superpowers/specs/HUI-2390-r3.md`

## 约束

- 不编辑 `server/internal/publishreward`、`server/internal/rewardrule`、`server/internal/extrajump`、`web/src/app/c`、`web/src/lib/visitor-experience.ts`。
- 不挂路由，不引入 shadcn。
- 草稿和 `needs_video` 不得写成发布成功。
- 夹具不是线上矩阵。不转码，不扣费，不调用 AICut。

## 任务

- [x] 相同租户、品牌、活动版本和素材哈希返回同一个草稿 id；新哈希或新期限另开版本，不覆盖已批准计划。
- [x] 视频夹具缺视频时返回 `needs_video`，且不转码、不扣费、不调用 AICut。
- [x] 运营商管理员、撤销代运营、跨租户、过期卖点都被拒绝，过期卖点不会被发布。
- [x] 商家发布记录之后，奖励写入、线索写入、顾客 UGC 仍为 0，且不调用 `GrantCustomerReward`。
- [x] 矩阵错误原样返回，活动状态保持 `open`。
- [x] `GOWORK=off go test ./internal/matrixhandoff/ -count=1` 通过。
