# HUI-2222 EcoTopNav Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 商家后台消费 eco-nav/v1，公共活动页不出现生态导航。

**Architecture:** 解析器与预览夹具留在 `web/src/lib/eco-nav`。顶栏只做手工切换。活动行上的任务按钮单独走交接计划。`/api/eco-nav` 在服务端读取目录，缺省回预览。

**Tech Stack:** Next.js、Vitest、既有 Go 服务不改。

**Spec:** `docs/superpowers/specs/2026-09-27-hui-2222-eco-top-nav-design.md`

## Global Constraints

- 当前 App `app_id` 固定 `touch`。
- 手工切换 `creates_handoff=false`，且拒绝带 `campaign_id` 的地址。
- 任务交接不扣费，查看线索不请求 lead-record。
- 公共页、首页、根布局不引用 `EcoTopNav`。
- 不修改 leads-engine、product-image-engine、GoBoost、goboost-fd、public-ai。
