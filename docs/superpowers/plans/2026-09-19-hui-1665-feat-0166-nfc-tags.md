## 1. 迁移 `0003_nfc_tags.sql`(additive,T0/T1 零改动)

- `nfc_tags(id, tenant_id→tenants, group_id 可空→nfc_tag_groups, store_id 可空→stores, link_id 非空→campaign_links, uid_hint 可空, label, status CHECK IN ('active','disabled') 默认 active, created_by, created_at, updated_at)`
- 索引:tenant/link/group。更新 `db_test.go` 的表清单断言(改既有用例的期望值,不减函数)。

## 2. 鉴权

`authz.ActionManageTags = "manage_tags"`:与 ActionManageMembers/ActionExportQR 同组 owner-only;staff 403 forbidden、游客 401、跨租户 404(资源不可见),全部沿用现有矩阵。

## 3. 纯逻辑包 `internal/tagcsv`(TDD 先行)

- `SanitizeField(s)`:字段以 `=` `+` `-` `@` 开头 → 前缀 `'`(CSV 注入防护);其余原样。
- `Build(rows []Row) (string, error)`:表头恒为 `label,short_code,url,store,group,uid_hint`;数据行逐字段过 SanitizeField,`encoding/csv` 负责引号/换行;前置 UTF-8 BOM(Excel 友好)。
- 测试:注入矩阵(`=cmd|...`、`+1`、`-2+3`、`@SUM`、正常值、含逗号/引号/换行、中文)、表头恒定、回读解析。

## 4. 存储层 `internal/store/store_tags.go`

- `NfcTagGroup` CRUD:Create(重名 → 冲突错误)、List、Delete(同事务先把组内标签 group_id 置 NULL 再删组——detach-on-delete)。
- `NfcTag` + `NfcTagView`(JOIN 出 code/campaign_id/store_name/group_name 供管理面展示与 CSV):
  - GetTag / ListTags(tenant 必带;可选过滤 campaign_id、group_id、store_id、status);
  - `CreateTagsBatch`:单事务生成 N 条标签;`bind_mode=shared` 全部绑 link_ids[0];`rotate` 第 i 条绑 link_ids[i%len];count 1..500;标签 label=前缀-序号(%03d);
  - `SetTagStatus`:同事务改标签 status **并** 对其绑定 link 走既有 SetLinkEnabled 同语义 UPDATE(标签停用→短码路由立刻进入既有五态停用态;恢复→复用)。共享 link 的多标签=同一入口的别名,停用其一即停用该入口(报告记录该拍板);
  - `PatchTag`:label / link_id(换绑活动) / group_id(空串=移出分组) / store_id(空串=解绑) / uid_hint(空串=清除),全部租户内校验;
  - `DeleteTag`:只删管理面记录,不动 campaign_link。

## 5. HTTP 面 `internal/httpapi/handlers_nfc.go`(全部 ActionManageTags=owner)

- `POST/GET /api/v1/nfc/tag-groups`、`DELETE /api/v1/nfc/tag-groups/{id}`
- `POST /api/v1/nfc/tags/batch`(campaign_id+link_ids+bind_mode+count+可选 store_id/group_id/label_prefix;校验 link 全部属于该租户该活动)
- `GET /api/v1/nfc/tags?campaign_id=&group_id=&store_id=&status=`、`GET /api/v1/nfc/tags/{id}`、`PATCH /api/v1/nfc/tags/{id}`、`DELETE /api/v1/nfc/tags/{id}`、`POST /api/v1/nfc/tags/{id}/status`
- `GET /api/v1/nfc/tags/export.csv`(同 list 过滤;URL 列 = `qrentry.PublicEntryURL(PUBLIC_BASE_URL, code)` 复用 1664 构造;PUBLIC_BASE_URL 缺失 → 503 `public_base_url_missing` fail-closed;`Content-Type: text/csv; charset=utf-8`、`Content-Disposition: attachment`、`Cache-Control: no-store`)
- 不加 FEATURE 开关(后台功能);公共面零改动。
