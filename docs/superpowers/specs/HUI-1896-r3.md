## 目标

公共页是匿名访客看到的商家活动，不是平台控制台。访客先看门店和这次活动能得到什么，再看到可做的动作；需要联系方式时才单独看到同意；提交之后才看到下一步。

工程门禁：浏览器，或仓库已有的 web 测试，在移动视口 390px 覆盖匿名进入、看懂活动、同意、拒绝营销、提交留资、返回。不要求真机。

## 行为

- 只用公开字段和已发布内容。不展示内部组织、代理、资产授权、CRM 状态、渠道余额或平台账户。
- NFC、二维码和短码打开同一活动。来源标记可以计数，不能改租户，也不能提高权限。
- 营销同意和这次留资本身分开。拒绝营销不挡住浏览活动。
- 「添加企微 / 关注 / 导航 / 点评」只在真实可用时出现。点击不是添加成功。`platform_result=unknown` 保持 unknown。
- 提交文案可以写已交给商家 X。客户系统还没确认收到时，文案是「待同步」，不是「销售已收到」。
- 「销售已收到」只允许测试注入的确认接收数大于 0。那个输入不是公共页默认状态。页面不传这个数。客户系统已接收仍然不是负责人已跟进，也不因此写成销售已收到。
- 公共页没有 EcoTopNav，没有平台注册，没有派诺订单。提交留资不创建平台账户。
- 弱网、暂停、结束、活动不存在、重复提交各自有可见状态。
- 曝光、点击、留资提交、CRM 接收保持四个计数，不合成一个转化。
- 不改跳转矩阵和 extrajump。不改 leads-engine。不引入 shadcn。沿用现有样式。

## 不做

不把票标成 Done。不宣称实机 NFC 覆盖。只测了 URL 或二维码时，NFC 硬件覆盖保持未验证。连接被拒绝的通知不是服务商通过。不编造扣费。不把机器点击写成真人采用。
