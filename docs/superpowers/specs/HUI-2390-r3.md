总指挥已经裁决。本文记录那个裁决，不再另问。

## 目标

Touch 活动与矩阵发布计划是两种对象。本包只保存交接草稿和对矩阵计划的引用，不复制账号池，不执行发布，不含社媒秘密。

顾客碰一碰、扫码、留资、发奖和 UGC 不在这条路上。商家计划被记下也不等于顾客发布成功。

## 行为

- 草稿从选定活动取得：租户、品牌、门店、活动 id 与版本、素材 id 与哈希、卖点、卖点期限、声明、返回位置令牌。
- 幂等键是租户、品牌、活动 id、活动版本、素材哈希、卖点期限。活动 id 用来区分同一品牌下的不同活动。相同键返回同一个草稿 id，且不改写已保存内容。
- 新的素材哈希或新的卖点期限生成新草稿版本。新版本不改写已批准计划的活动内容、素材、卖点、期限、声明、返回位置和计划引用。
- 已批准计划保持批准，直到另一个版本被明确确认。明确确认只批准被点名的那一版，并结束同一活动上其他计划的批准；旧内容仍不被覆盖。
- 建立草稿不执行发布。文案不得包含「发布成功」。
- 只接受视频的夹具在没有视频素材时返回 `needs_video`。这不是成功。不转码、不扣费、不调用 AICut。
- 运营商管理员不是品牌发布权。撤销的代运营被拒绝。跨租户被拒绝。跨品牌被拒绝。过期卖点被拒绝，且不会被发布。
- 商家发布记录不得写顾客奖励、顾客 UGC 或线索。不调用 `GrantCustomerReward`。奖励写入和线索写入保持 0。
- 矩阵客户端错误原样返回。交接文档上的活动状态保持 `open`，不锁定活动。
- 本包没有顾客 EcoTopNav，不涉及 NFC 硬件。
- 夹具不是线上矩阵。Service NOT_VERIFIED。Billing NOT_VERIFIED。Production NOT_AUTHORIZED。Human UNKNOWN。

## 不做

不挂 HTTP。不改公共访客页。不改 `publishreward`、`rewardrule`、`extrajump`。不接入真实矩阵、计费或 AICut。不把夹具结果写成发布成功。
