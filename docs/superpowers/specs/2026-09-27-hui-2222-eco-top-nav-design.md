# HUI-2222 碰一碰商家后台接入 EcoTopNav

| 字段 | 值 |
| --- | --- |
| 日期 | 2026-09-27 |
| Linear | HUI-2222 |
| 契约 | public-ai `eco-nav/v1` @ `be6d7d3`，消费方式对齐观澜 HUI-2219 |
| 基线 | `origin/main` `63acba8` |

## 目标

认证后的商家后台挂上 EcoTopNav。当前 App 固定为 `touch`，品牌展示名来自文档。门店、活动、素材、NFC 仍是碰一碰本地信息架构。

公共活动页、首页和根布局不挂生态导航。

## 两种跳转

| 表面 | 意图 | 创建交接 | 创建或恢复目标项目 | 携带 campaign |
| --- | --- | --- | --- | --- |
| 顶栏应用名 | `manual_switch` | 否 | 否 | 否，带 `campaign_id` 的地址直接拒绝 |
| 活动行「为本活动制作图片/视频」 | `task_handoff` | 是 | 是 | 是 |
| 活动行「查看本活动线索」 | `task_handoff` | 是 | 否 | 是，但不读取 lead-record |

没有 Registry 允许列表时不伪造跳转地址。不向客户扣费。获客 HUI-1680 的契约对端不写成活的碰一碰活动已经打通。

## 代运营

会话角色为 `agent` 时顶栏写「正在为 X 商家工作」。切换商家后清空活动、二维码和标签列表；迟到的上一商家响应丢弃。额度在离开原 scope 后显示「额度需确认」，不沿用上一商家金额。

## 不做

不改 public-ai、GoBoost、获客或产品图。不新增 lead-record 取数路由。不把预览夹具当成已接上的公共身份。
